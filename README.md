# Project2
This project presents an interactive web map that explores the spatial relationship between food store locations and community income in the City of Los Angeles. The map displays McDonald’s, Trader Joe’s, and Whole Foods locations together with median household income by census tract. Users can filter one or more brands, compare store counts across income categories, and click store locations to view their addresses, census tracts, and income information. Store data were obtained from OpenStreetMap, and income data came from the U.S. Census Bureau’s 2020–2024 American Community Survey Five-Year Estimates. The map and interactive functions were created with ArcGIS Online and ArcGIS Experience Builder and published through GitHub Pages.
